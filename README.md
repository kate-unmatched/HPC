# Лабораторные работы по предмету "Высокопроизводительные вычисления"

### [Лабораторная работа №1 - Перемножение матриц](Lab_1_HPC)

В рамках лабораторной работы реализовано умножение квадратных матриц на CPU и GPU с использованием технологии CUDA. Параллелизация выполнена на уровне элементов результирующей матрицы, где каждый поток GPU вычисляет отдельный элемент для эффективного использования вычислительных ресурсов. Проведённые эксперименты показали значительное ускорение на GPU по сравнению с CPU при увеличении размера матриц.

### [Лабораторная работа №2 - Сумма элементов вектора](Lab_2_HPC/)

В работе реализованы два алгоритма суммирования элементов вектора: последовательный на CPU и параллельный на GPU с использованием CUDA и алгоритма reduction. Проведены эксперименты на различных размерах входных данных с измерением времени выполнения и расчётом ускорения. Показано, что GPU эффективен только при больших объёмах данных, где параллелизм компенсирует накладные расходы.

## [Лабораторная работа №3 - Salt and Pepper](Lab_3_HPC/)

В рамках лабораторной работы реализована обработка BMP-изображений на GPU с использованием технологии CUDA. Программа выполняет удаление импульсного шума типа Salt-and-Pepper с помощью медианного фильтра 3×3. Каждый поток GPU обрабатывает отдельный пиксель изображения, формируя окно соседних значений и выбирая медиану. Для оптимизации доступа к пикселям используется texture memory CUDA. Дополнительно рассчитываются метрики качества восстановленного изображения: MSE и PSNR. Проведённые эксперименты показали, что медианный фильтр эффективно удаляет шум при небольшом уровне зашумления, а время обработки на GPU остаётся практически постоянным при изменении процента шума.

## [Лабораторная работа №4 - Function Approximation by a Polynomial Using a Genetic Algorithm](Lab_4_HPC/)

В рамках лабораторной работы реализован генетический алгоритм для аппроксимации функции полиномом четвёртой степени. Один индивид популяции представляет собой набор коэффициентов полинома, а качество решения оценивается с помощью fitness-функции на основе суммы квадратов ошибок. Основные операции алгоритма перенесены на GPU: расчёт fitness, скрещивание, мутация и сортировка популяции. Для генерации случайных чисел используется CURAND, а для отбора лучших индивидов применяется Thrust. Проведённые эксперименты показали, что алгоритм успешно находит коэффициенты, близкие к исходным, и достигает малого значения ошибки аппроксимации.
