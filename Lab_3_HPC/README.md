# Лабораторная работа №3. Salt-and-pepper noise filtering on GPU

## Описание

В проекте реализован медианный фильтр 3×3 на GPU с использованием CUDA и texture memory для удаления импульсного шума (salt & pepper) с изображений.

Дополнительно реализованы:

* генерация шума с заданным уровнем
* количественная оценка качества восстановления (MSE, PSNR)

## Технологии

* C++
* CUDA
* EasyBMP


## Возможности

* Параллельная фильтрация изображения на GPU
* Использование texture memory для эффективного доступа к пикселям
* Генерация salt & pepper шума
* Оценка качества восстановления изображения

---

## Использование

### 1. Генерация шума

```
noise clean.bmp noisy.bmp 0.1
```

где `0.1` — 10% шума

### 2. Фильтрация (CUDA)

```
Lab_3_HPC.exe noisy.bmp output.bmp
```


### 3. Оценка качества

```
metrics clean.bmp output.bmp
```


## Метрики

### MSE (Mean Squared Error)

Среднеквадратичная ошибка между изображениями

### PSNR (Peak Signal-to-Noise Ratio)

Основная метрика качества восстановления

Интерпретация:

* > 40 dB — отличное качество
* 30–40 dB — хорошее
* < 25 dB — заметная деградация



## Эксперимент

При увеличении уровня шума наблюдается:

* рост MSE
* снижение PSNR
* ухудшение визуального качества

Медианный фильтр показывает наилучшие результаты при уровне шума до ~15–20%.
