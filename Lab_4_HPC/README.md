## Основная реализация

Цель программы - найти коэффициенты полинома, который аппроксимирует заданный набор точек.

Аппроксимирующий полином имеет степень не выше 4:

    g(x) = c0 + c1*x + c2*x^2 + c3*x^3 + c4*x^4

Таким образом, один индивид генетического алгоритма представляет собой набор из пяти коэффициентов:

    Individual = [c0, c1, c2, c3, c4]

Входной набор точек генерируется внутри программы на основе заранее заданного полинома с добавлением нормального шума. Это было сделано для проверки корректности работы алгоритма, так как истинные коэффициенты известны заранее.

Основные этапы работы алгоритма:

1. Генерируется набор точек функции.
2. Создаётся начальная случайная популяция индивидов.
3. Для каждого индивида на GPU вычисляется значение fitness.
4. Популяция сортируется по fitness с помощью Thrust.
5. Из лучших индивидов формируется новая популяция с помощью crossover.
6. К части генов применяется mutation с использованием CURAND.
7. Процесс повторяется до достижения заданного качества или максимального числа поколений.
8. В конце выводятся найденные коэффициенты, лучшее значение fitness, номер последнего поколения и время работы на GPU.

Значение fitness рассчитывается как сумма квадратов ошибок между исходными значениями функции и значениями аппроксимирующего полинома:

    fitness = sum((g(x_i) - y_i)^2)

Чем меньше значение fitness, тем лучше индивид аппроксимирует исходную функцию.

## Реализация на GPU

В текущей версии на GPU выполняются основные операции генетического алгоритма:

| Операция | Реализация |
|---|---|
| Расчёт fitness | CUDA kernel calculateFitnessKernel |
| Сортировка популяции | thrust::sort |
| Скрещивание | CUDA kernel crossoverKernel |
| Мутация | CUDA kernel mutationKernel |
| Генерация случайных чисел | CURAND |
| Замер времени | CUDA events |

На CPU остаются только вспомогательные действия:

| Операция | Назначение |
|---|---|
| Генерация точек | Формирование тестового набора данных |
| Генерация начальной популяции | Создание стартового набора коэффициентов |
| Задание параметров алгоритма | Настройка размера популяции, числа точек, количества поколений и параметров мутации |
| Вывод результата | Печать найденных коэффициентов, fitness, поколения остановки и времени выполнения |

## Основные параметры алгоритма

В программе используются следующие параметры:

| Параметр | Значение | Описание |
|---|---:|---|
| pointCount | 500 | Количество точек для аппроксимации |
| populationSize | 1000 | Размер популяции |
| POLYNOMIAL_DEGREE | 4 | Максимальная степень полинома |
| COEFF_COUNT | 5 | Количество коэффициентов полинома |
| maxIter | 5000 | Максимальное число поколений |
| maxConstIter | 700 | Максимальное число поколений без улучшения fitness |
| Em | 120.0 | Среднее число мутируемых генов |
| Dm | 30.0 | Дисперсия числа мутируемых генов |
| aimedFitness | 5.5 | Целевое значение fitness для досрочной остановки |
| seed | 42 | Начальное значение генератора случайных чисел |

## Используемая функция

Для генерации тестовых данных используется полином:

    f(x) = 2.0 - 1.5*x + 0.3*x^2 + 0.1*x^3 - 0.01*x^4

Истинные коэффициенты:

    c0 = 2.0
    c1 = -1.5
    c2 = 0.3
    c3 = 0.1
    c4 = -0.01

К значениям функции добавляется нормальный шум, поэтому итоговый fitness для истинных коэффициентов не равен нулю.

## Анализ результата

В результате работы программы генетический алгоритм успешно подобрал коэффициенты полинома, аппроксимирующего исходный набор точек. Найденный полином оказался близок к функции, на основе которой генерировались тестовые данные.

Так как входные точки создавались с добавлением нормального шума, полное совпадение найденных коэффициентов с исходными не требуется. Наличие шума приводит к тому, что даже истинный полином имеет ненулевое значение ошибки. Поэтому качество работы алгоритма оценивается не по абсолютному совпадению коэффициентов, а по близости найденного значения fitness к fitness исходного полинома.

Полученный результат показывает, что алгоритм смог приблизиться к исходной зависимости. Найденные коэффициенты отличаются от истинных незначительно, а итоговое значение fitness оказалось близким к ошибке, полученной на исходных коэффициентах. Значит, генетический алгоритм корректно выполняет поиск решения в пространстве коэффициентов.

Наиболее точно были восстановлены коэффициенты при линейном, кубическом и четвёртой степени полинома. Небольшие отклонения свободного коэффициента и коэффициента при квадрате можно объяснить влиянием шума во входных данных, а также стохастическим характером генетического алгоритма.

В процессе работы алгоритм последовательно улучшал качество популяции. На начальных поколениях значение fitness было большим, так как начальная популяция формировалась случайным образом. После применения отбора, скрещивания и мутации качество решений постепенно улучшалось, и алгоритм достиг заданного целевого значения fitness.

GPU-реализация позволила перенести основные вычислительно затратные операции на видеокарту. На GPU выполнялись расчёт fitness для всей популяции, сортировка индивидов, скрещивание, мутация и генерация случайных чисел.

## Выводы

В ходе выполнения лабораторной работы был реализован генетический алгоритм для аппроксимации функции полиномом четвёртой степени.

Каждый индивид популяции представлял собой набор коэффициентов полинома. Для оценки качества решения использовалась fitness-функция, основанная на сумме квадратов ошибок между исходными точками и значениями аппроксимирующего полинома. Чем меньше значение fitness, тем лучше найденный полином описывает исходные данные.

В реализации были использованы основные операции генетического алгоритма:

- формирование начальной популяции;
- вычисление fitness;
- отбор лучших индивидов;
- скрещивание;
- мутация;
- проверка условий остановки.

Основная часть алгоритма была перенесена на GPU. Для этого использовались CUDA-ядра, библиотека CURAND для генерации случайных чисел и библиотека Thrust для сортировки популяции. Подход позволил организовать параллельную обработку индивидов и выполнить вычисления в соответствии с требованиями задания.

Полученные результаты показали, что генетический алгоритм способен находить коэффициенты полинома, близкие к исходным значениям. Несмотря на наличие шума во входных данных, найденное решение обеспечивает малую ошибку аппроксимации. Подтверждена работоспособность реализованной CUDA-версии алгоритма.

Поставленная задача была выполнена: программа генерирует набор точек, подбирает коэффициенты аппроксимирующего полинома, выводит лучшее значение fitness, номер последнего поколения и время обработки на GPU.
